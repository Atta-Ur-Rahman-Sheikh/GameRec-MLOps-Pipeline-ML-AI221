\begin{abstract}
We present \textbf{GameRec}, an end-to-end machine-learning pipeline that fuses Steam catalogue metadata with RAWG annotations to power a hybrid game recommender, a multi-label player-type classifier, a content-only popularity regressor, latent-genre clustering, and release-month seasonality analysis. Item representations combine TF--IDF text vectors with truncated singular value decomposition (LSA) latent factors; a lightweight FastAPI service serves inference from serialized artifacts while a Prefect flow validates data and model bundles in CI/CD. We discuss design trade-offs, evaluation caveats, and MLOps lessons for student-scale projects.
\end{abstract}
