\section{MLOps architecture}
\subsection{Serving path}
The FastAPI application eagerly loads serialized NumPy, SciPy sparse, Joblib, and JSON artifacts at startup into a singleton \texttt{ArtifactBundle}. Routers expose thin validation layers; core scoring routines live in a pure service layer importable by tests without HTTP \cite{fastapi}.

\subsection{Dockerization}
A slim Python 3.12 image installs pinned dependencies, copies only the \texttt{app} package, and exposes port 8000. Large matrices remain \textbf{outside} the image: \texttt{docker-compose} mounts \texttt{artifacts/recommender} read-only, mirroring staging best practices where model blobs live in object storage.

\subsection{Continuous integration}
GitHub Actions runs Ruff lint/format checks, pytest using a checked-in micro-fixture dataset (re-fit reduced models) to keep jobs under minutes, and a non-publishing Docker build for early Dockerfile regressions.

\subsection{Orchestration}
A Prefect 3 flow validates that raw dataset paths exist and enumerates missing required artifact filenames before deployment, complementing---not replacing---interactive notebook training \cite{prefect}.

\subsection{Threat model and limitations}
The API trusts local artifact integrity; there is no adversarial robustness analysis. Rate limiting and auth are omitted for coursework scope but noted for production hardening.
