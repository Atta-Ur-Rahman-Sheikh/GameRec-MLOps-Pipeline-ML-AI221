\section{Introduction}
Video game catalogues contain high-dimensional, sparse metadata: genres, community tags, platform flags, and long-form descriptions spanning indie micro-titles to AAA franchises. Consumers struggle to navigate this space, while course-scale recommender projects rarely combine \emph{credible} content models with an honest deployment story.

\textbf{Contributions.} (i)~A \textbf{hybrid recommender} blending TF--IDF cosine similarity, LSA latent-factor similarity, and Bayesian-smoothed popularity. (ii)~A \textbf{multi-label player archetype classifier} trained on weak labels derived from interpretable tag rules. (iii)~A \textbf{cold-launch popularity regressor} with strict exclusion of leakage-prone review aggregates from inputs, using only content-derived features and release metadata. (iv)~\textbf{Hidden-genre discovery} with KMeans on normalized LSA vectors, explained via lift-based tag summaries. (v)~A \textbf{release-month seasonality study} per theme, with a shape-only forecast baseline isolating Halloween and sports-calendar effects. (vi)~An \textbf{MLOps packaging}: FastAPI inference, Docker, GitHub Actions CI on fixture artifacts, and Prefect validation of training outputs.

\textbf{Scope.} We do not claim state-of-the-art accuracy---the Bayesian-shrunk popularity target has low variance---rather we emphasize reproducibility, leakage hygiene, and deployability suitable for classroom demonstration.
