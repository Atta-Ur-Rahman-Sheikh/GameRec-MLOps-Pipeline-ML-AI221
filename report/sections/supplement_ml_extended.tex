\subsection{Why LSA instead of deep transformers (classroom justification)}
Large language models could encode descriptions into contextual embeddings, but they introduce heavy GPU requirements, fragile API dependencies, and opaque vectors for viva explanations. Truncated SVD on TF--IDF offers a classical, well-understood matrix factorization: each latent dimension is a linear combination of token loadings inspectable via highest absolute coefficients. Instructors can draw the parallel to classical collaborative filtering where user--item matrices factorize analogously---here the ``users'' are latent topics and the ``items'' are games.

\subsection{Hybrid weighting semantics}
Let semantics dictate weights. Item--item recommendation should trust latent geometry when textual symmetry fails (synonyms, stem variants). User--item cold start should emphasise popularity more strongly because sparse user utterances collapse TF--IDF vectors onto overly generic tokens. The project exposes weights as API fields so demos can tune live during the viva.

Document the sensitivity: if $w_{\text{pop}}\rightarrow 1$, the system degenerates to popularity ranking; if $w_{\text{lsa}}\rightarrow 1$, niche duplicates surface even when tags mismatch literally. The sweet spot is empirical but usually lands near $0.5/0.3/0.2$ splits for catalogue navigation.

\subsection{Bayesian popularity shrinkage intuition}
Raw averages of star ratings overweight titles with tiny samples---a five-star indie with twelve votes is not statistically comparable to a four-star blockbuster with two hundred thousand. Bayesian shrinking pulls estimates toward the global mean proportional to uncertainty. This makes the regression target smoother; emphasize in the viva that \emph{this smoothing lowers achievable $R^2$}, and that naive overfitting would mistake memorized review aggregates for content.

\subsection{Mathematical supplement}
For interested readers, the TF--IDF weight for term $t$ in document $d$ is
\begin{equation}
\text{tfidf}(t,d)=\log(1+f_{t,d})\cdot \log\frac{1+N}{1+\mathrm{df}_t}} ,
\end{equation}
with sublinear term frequency $f_{t,d}$ matching the implementation's \texttt{sublinear\_tf=True}. Latent factors arise from
\begin{equation}
\ell_i = \frac{S_k v_i}{\lVert S_k v_i \rVert_2 + \varepsilon},
\end{equation}
where $v_i$ is the sparse TF--IDF row and $S_k$ the projected SVD mapping.
